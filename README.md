## 先分清：你要的是顶级域名，还是免费二级域名

雨云的域名服务里有两个完全不同的东西，新手最容易混。

**顶级域名**：`yourname.com` 这种，需要付费，按年计费，需要实名认证和信息模板审核。

**免费二级域名**：`yourname.某个主域名` 这种，雨云提供，不花钱，直接在后台开。官方的免费二级域名说明里写得很直白——如果你没有域名、又急着测试网站，可以用它，而且能直接解析到雨云自己的产品上。

这个免费二级域名不是阉割版的玩具，官方明确支持两个实用功能：解析到自定义地址（不限于雨云产品，也包括你自己的服务器和第三方主机），以及一键启用 Cloudflare CDN，不用你去 Cloudflare 手动加域名改 NS。

但它有几个限制，必须提前知道：

- 主机名不能用 `www` 和 `@`，官方给的理由是防止不公平占用；
- 解析到自定义地址要消耗积分，指向雨云自家产品则推荐使用；
- **免费二级域名不支持申请 SSL 证书**，要用自己的域名才行。

所以判断很简单：只是测试、临时演示、跑个内网项目，免费二级域名够用；要做正式站点、要上 HTTPS、要写进名片或宣传物料，那就得买顶级域名。

## 注册前要准备什么

两件事，缺一样都到不了下一步。

**第一，实名认证资料。** 个人准备身份证，企业准备营业执照。这是一致的要求，多个教程都强调申请信息必须真实有效，否则审核过不了。

**第二，信息模板。** 第一次在雨云注册域名，必须先建一个信息模板，按提示如实填写。模板提交后会进入审核状态，审核通过域名才自动注册、解除冻结。

这里有个很多人踩过的坑：注册完域名，控制台显示状态是"**冻结中**"，于是以为失败了。其实这只是信息模板还在审。等模板审核通过，域名会自动注册并解冻。模板只在首次创建时需要审核，后续没有信息变更就不再重复审，再买域名会快很多。

顺带说一句关于隐私保护的事。根据第三方测评的记录，雨云域名注册是与西部数码合作的，除了 `.cn` 和 `.中国` 等特定后缀，其他后缀在查 whois 时只显示注册省份，其余字段显示为 `REDACTED FOR PRIVACY`。这个细节对不想公开个人信息的个人站长挺有用。

## 雨云域名注册的完整操作流程

实际路径不复杂，关键是每一步别跳。

1. 登录雨云，进入控制台，在云产品里找到**域名服务**，点进**域名注册**。
2. 在搜索框输入你想要的名称加后缀，比如 `你的名字 + . + 后缀`，回车查询。想看别的后缀往下滑，可以横向对比。
3. 看到价格和可注册状态后，点"立即注册"。此时如果没有信息模板，系统会引导你新建。
4. 选择注册年限（首次一般默认 1 年，之后按年续费）。注意域名不是永久资产，首次付款的有效期就是 1 年。
5. 确认订单并支付。雨云域名走的是账户余额，所以**首次购买前建议先去费用中心充值**，公开教程里给的参考充值区间是 30–100 元，够买一个常规后缀。
6. 支付完成，域名进入"冻结中"状态，等模板审核通过后自动解冻。

如果卡在"余额不足"，不是系统故障，就是第 5 步没做。

## 备案这件事，别等买完才发现

这一条必须写在显眼位置。

国内服务器提供网站服务，域名需要备案，这是法律要求。但关于"雨云能不能备案"，公开资料里的说法并不一致：

- 较早的一批教程（2024 年前后流传较广的那几篇）明确写着"目前雨云服务器暂时不支持域名备案"；
- 较新的一篇教程则提到，雨云备案需要联系网站客服对接，并附了具体流程截图。

这两条信息存在冲突，很可能是因为平台能力在这期间发生了变化。文章没有能力替你确认哪个是当前状态，所以给出一个可执行的做法：**如果你的网站必须走国内备案，下单前先在控制台找在线客服问清楚当前是否支持、走什么流程。** 这比事后发现域名买了不能用要划算得多。

反过来，如果你的站点托管在境外服务器，或者只是自己用、不对外提供经营性信息服务，备案就不是拦路虎。

## 域名到手后要配的三件事

注册成功只是拿到了名字，能不能访问是另一回事。

**DNS 服务器。** 默认用雨云提供的解析服务器就能用。想换成自己的（比如走 Cloudflare 或自建 DNS），进域名控制台，点"设置 DNS 服务器"，勾选"使用自定义 DNS 服务器"，填入地址后保存。注意这一步改的是 DNS 服务器，和下面加解析记录是两回事，别搞混。

**解析记录。** 有服务器、要通过域名访问的，进控制台点"设置 DNS 解析"→"添加解析记录"。主机名填 `@` 或 `www`；解析目标如果指向雨云自家的服务器产品，可以直接选产品；TTL 可以调，最小可以设到 1 分钟，方便调试。加完点添加就生效，之后点记录右侧的"操作"可以编辑或删除。

**SSL 证书。** 不做这一步，浏览器地址栏会显示不安全。雨云自己就提供证书服务，官方文档里的免费方案是 TrustAsia 免费 SSL 证书，DV 类型、支持多域名、支持 DNS 验证——签发流程是：选证书 → 验证域名所有权 → 下载证书。对个人站和小型站点够了。整个流程和证书类型说明可以在同一个入口看到：👉 [了解雨云 SSL 证书方案](https://www.rainyun.com/MzA2MTc2_)。

要提醒的一点是，申请证书需要一个你能控制解析的域名。这就是上文说的免费二级域名的硬伤——它本身不支持申请 SSL 证书，所以如果你打算上 HTTPS，最后还是得买顶级域名。
